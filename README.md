# G&G AlmaPura — web real v3

Esta versión se ha construido como web HTML/CSS/JS usando únicamente los archivos reales materializados en la conversación. No se han generado ilustraciones nuevas, portadas nuevas, cartas nuevas, fondos nuevos ni productos nuevos.

## Contenido
- `index.html` — página de scroll vertical responsive.
- `styles.css` — estilos mobile-first, tablet y ordenador.
- `script.js` — cambio de idioma ES/EN y cambio de imágenes/enlaces por idioma.
- `assets/` — copias sin modificar de los archivos aportados.
