3. Finalidades del tratamiento

Los datos se utilizarán para responder consultas, gestionar comunicaciones relacionadas con libros, oráculos, ilustraciones, productos creativos o la aplicación AlmaPura G&G, atender posibles incidencias o colaboraciones y cumplir obligaciones legales que pudieran resultar aplicables.

4. Base jurídica

La base jurídica para tratar los datos facilitados por correo electrónico es el consentimiento de la persona que contacta voluntariamente y el interés legítimo de responder a las comunicaciones recibidas. Cuando corresponda, el tratamiento también podrá basarse en el cumplimiento de obligaciones legales.

5. Conservación de los datos

Los datos se conservarán durante el tiempo necesario para responder la consulta o gestionar la comunicación. Posteriormente podrán conservarse bloqueados durante los plazos legalmente exigibles, si fuera necesario para atender responsabilidades u obligaciones legales.

6. Comunicación de datos a terceros

No se cederán datos personales a terceros, salvo obligación legal o cuando sea necesario para la prestación de servicios técnicos vinculados a la web, el correo electrónico, el alojamiento o plataformas externas.

Esta web está alojada en GitHub Pages. Las compras, descargas o interacciones comerciales se realizan, en su caso, a través de plataformas externas como Etsy, Amazon, MakePlayingCards/MPC o tiendas de aplicaciones. Cada plataforma actúa conforme a sus propias políticas legales y de privacidad.
